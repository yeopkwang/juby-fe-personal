# UI 리디자인 결과 2026-10-29

지시서: "UI 리디자인 지시서 2026-10-29"(사용자가 대화에 붙여 넣은 원문). 시작 커밋은 `feat/detail-quick-actions`의 `6129bec`이고 푸시하지 않는다.
판정은 운영 빌드(`vite preview`) + Playwright(크롬)로 1440×900·1920×1080·375×812에서 한다. 캡처와 판정 스크립트는 저장소에 두지 않는다(세션 임시 폴더).

## 0. 미리 정한 것

- U-0: 시안 두 벌(A 차분·B 브랜드)을 만들고 멈춰 물었다. **사용자가 B안(머리글 띠만 진한 초록)을 골랐다.**
- 등락 색: 지시서 팔레트의 상승 `#F04452`·하락 `#3182F6`은 흰 바탕 3.71:1, 페이지 바탕 3.48:1이라 작은 글자가 판정 3(4.5:1)에 걸린다.
  **사용자 결정: 차트·그림은 그대로 쓰고, 글자에는 진한 값(상승 `#D9283A` 4.87:1, 하락 `#1B64DA` 5.41:1)을 쓴다.**
- 저장소: 사용자 결정으로 팀 저장소(`~/Desktop/JUBY-FE`) `feat/detail-quick-actions` 위에 이어서 커밋한다(푸시 안 함).
- 녹화 응답: 2026-09-30에 녹화가 사라진 뒤로 스웨거 모양대로 지은 응답을 쓴다(CLAUDE.md "브라우저로 검증하는 법"). 지시서 0절대로 상세의
  봉 가격을 현재가와 같은 가격대로 고쳤다 — 삼성전자 마지막 종가 71,000원, 현재가 71,500원(+0.70%), 3개월 봉 65,300~74,700원.
- 상세 응답(`StockDetailRes`)에는 시각이 없다(2026-10-29 스웨거). U-4의 "기준 시각"은 응답을 받은 시각으로 적는다.

## 4. 비고

1. **등락 글자 색**(0절): 지시서 팔레트의 `#F04452`·`#3182F6`은 작은 글자에 대비가 모자라, 사용자 결정으로 글자는 `#D9283A`·`#1B64DA`를 쓴다.
   차트 봉·막대·선 같은 그림은 지시서 값 그대로다.
2. **저장소**: 지시서는 "지금 작업 브랜치"였고 전역 규칙은 개인 저장소였다. 사용자 결정으로 팀 저장소 `feat/detail-quick-actions`에 이어 커밋했다(푸시 안 함).
3. **녹화 응답**: 녹화가 2026-09-30에 사라진 뒤라 스웨거 모양대로 지은 응답을 쓴다. 지시서대로 상세 봉 가격을 현재가 가격대로 맞췄고,
   실서버처럼 토큰 없는 비공개 경로는 401로 막게 했다(그 전에는 비로그인 성향테스트가 서버 문항을 받아 "임시 문항" 안내가 안 떴다).
4. **기준 시각**(U-4): 상세 응답에 시각이 없어(`StockDetailRes`) 받은 시각을 적는다(`receivedAt`, 1분 캐시에서 꺼내도 처음 받은 때).
5. **간격 토큰**(0절 "간격은 토큰만"): 새로 짜거나 다시 짠 곳만 `--space-*`다. 나머지 옛 px 값을 한꺼번에 반올림하면 이번에 배치를 건드리지 않기로 한
   로그인 화면까지 흔들려 남겼다. 글자 크기는 26가지를 13단계 토큰으로 모두 옮겼다.
6. **단추 3종 예외**: 카카오·네이버 로그인 단추는 각 회사 지침 색이다(토큰 `--color-kakao`·`--color-naver`).
7. **되돌릴 수 없는 확정**(탈퇴·대화 지우기): 빨강을 경고로 쓰지 않으므로 primary로 두고 취소를 secondary로 했다. 되돌릴 수 없다는 건 확인 상자 글이 알린다.
8. **하트 이름**: 상세 토글은 지시서대로 "관심종목 추가/해제"다. 홈 시세표는 같은 이름의 단추가 100개 늘어서 읽는 쪽이 어느 종목인지 몰라
   "{종목명} 관심종목 추가/해제"를 그대로 두고 색·모양 규칙만 맞췄다.
9. **홈 카드 머리말**(U-5): "무엇을 기준으로 골랐는지"를 확인하려고 백엔드 소스를 읽었더니(dev `3dc3f3a`, 읽기만) 종목은 테마마다 정해 둔 셋이고
   전략 결과로 고르지 않는다(`LeadingStockTheme`). 예전 머리말 "SMA 이동평균선 전략 · 1년 기준으로 뽑은"이 사실과 달라 "테마마다 대표 종목을 하나씩 골라
   1년 주가 흐름을 보여드려요"로 바꿨다. 큰 숫자의 뜻(1년 주가 변화)은 그대로이고 라벨만 "1년간 주가 변화"로 고쳤다. 두 필드의 뜻은 백엔드에 묻는다(`docs/남은-일.md` 백엔드 12).
10. **색을 뺀 값**: 고가·저가(시세 요약), 매수·매도(백테스트 가이드)는 오르내림이 아니라 빨강·파랑을 걷었다.
11. **비로그인 바로 가기**(U-3): 예전(6129bec)엔 비로그인이 백테스트 화면으로 가 종목만 채웠다. 지시서대로 "로그인 필요" 배지를 달고 로그인으로 보낸다
    (로그인하면 그 상세로 돌아온다). 받는 화면의 비로그인 처리는 종목이 실려 오는 사이 로그아웃한 경우를 위해 남겼다.
12. **고친 판정식**(옛 동작을 전제로 적은 것·잘못 센 것): U1-4가 클릭되는 카드 안의 등락 숫자를 "링크를 파랑으로 칠함"으로 셌다 — 숫자는 등락으로 본다.
    U1-3이 꾸밈 글(aria-hidden, 로고 "JUBY")을 셌다. U5-4가 종목코드로 끝나는 이름 칸을 숫자 칸으로 셌다. U7이 문단 상자 폭을 글줄 폭으로 셌다 —
    실제 그려진 줄 폭으로 고쳤다. 가짜 뉴스 요약을 길게 바꾸자 AI 판정의 기다림 조건("요약입니다")이 뉴스 글과 겹쳐 대화 칸 안으로 좁혔다.
