# 코스피·코스닥 지수 API 제안 (프론트, 2026-10-29)

프론트가 모든 화면 아래에 지수 띠(코스피·코스닥)를 먼저 만들어 두었다. 지금은 예시 값을 그리고 띠에 "예시 값"이라고 적는다.
아래 모양으로 주면 프론트는 스위치 하나(`src/api/market.ts`의 `USE_SAMPLE`)만 바꾸면 붙는다.
다르게 줘도 된다. 그러면 프론트가 그 파일 하나를 응답에 맞춘다.

## 요청

`GET /api/stocks/indices`. 매개변수는 없다.

- **로그인 없이 부를 수 있어야 한다.** 띠는 비로그인 화면에도 뜬다.
- `/api/stocks/**`는 이미 공개(`SecurityConfig`의 `allowUris`)라 보안 설정을 고치지 않아도 된다. `/api/market/**`는 로그인해야 열려서 쓸 수 없다.
- 경로가 `/api/stocks/{stockCode}`와 겹치지만, 글자로 적은 경로가 우선이라 `leading-stocks`·`search`처럼 괜찮다.

## 응답

다른 API와 같은 `{ isSuccess, code, message, result }`로 싼다.

```json
{
  "isSuccess": true,
  "code": "STOCK200_6",
  "message": "지수 조회에 성공했습니다.",
  "result": {
    "indices": [
      { "indexCode": "0001", "indexName": "코스피", "currentValue": 2612.43, "changeValue": 12.31, "changeRate": 0.47 },
      { "indexCode": "1001", "indexName": "코스닥", "currentValue": 745.10, "changeValue": -3.20, "changeRate": -0.43 }
    ]
  }
}
```

| 필드 | 타입 | 뜻 |
|---|---|---|
| `indexCode` | 문자열 | 증권사 업종 코드. 코스피 `0001`, 코스닥 `1001` |
| `indexName` | 문자열 | 띠에 그대로 적는 이름 |
| `currentValue` | 숫자 | 현재 지수(포인트). 장이 끝났으면 마감 값 |
| `changeValue` | 숫자 | 전일 대비(포인트). **내리면 음수** |
| `changeRate` | 숫자 | 전일 대비율(%). 0.47이면 +0.47%. **내리면 음수** |

- 부호를 값에 붙여 주면 증권사 부호 코드(`prdy_vrss_sign`)는 따로 주지 않아도 된다.
- 숫자는 JSON 숫자가 좋다. 증권사처럼 문자열(`"2612.43"`)로 와도 프론트가 읽는다.
- 프론트는 받은 순서대로 그린다. 줄을 늘리면(코스피200 등) 그만큼 더 그린다.
- `changeValue`·`changeRate`는 비어도 된다. 그 자리만 비운다. 이름이나 지수가 빈 줄은 프론트가 뺀다.

## 서버에 담아 두기 (부탁)

**띠는 모든 화면에 떠 있고, 장중(평일 9:00~15:35)이면 탭이 보이는 동안 1분마다 다시 부른다.**
그래서 요청 수가 보고 있는 사람 수를 따라 는다.

- 요청마다 증권사를 부르면 증권사 호출도 사람 수만큼 늘어난다.
- 서버가 지수를 담아 두고(예: 장중 30초~1분마다 받아 메모리에 둔다) 요청에는 담아 둔 값을 주면 좋겠다.
- 장 밖에는 마지막 값을 그대로 주면 된다.

지금 프론트는 이 API가 요청마다 증권사를 부른다고 보고, 서버에 증권사 토큰이 없을 것 같은 때는 부르지 않는다
(주말 토 15:45~월 16:05와 평일 15:45~16:05 — 홈 카드 그래프와 같은 규칙).
토큰이 없을 때 부르면 서버 전체의 "1분 1회 토큰 발급"을 써 버려, 바로 뒤 사용자가 연 종목 상세가 1분 넘게 기다린다(`docs/남은-일.md` 백엔드 10번).
**담아 둔 값을 준다고 알려 주면 프론트가 이 제한을 걷는다.**

선택: 값을 받은 시각(`baseTime`, 예: `"2026-10-29T15:30:00"`)을 같이 주면 띠에 "15:30 기준"을 정확히 적을 수 있다.
지금은 프론트가 응답을 받은 시각을 적는다.

## 증권사에서 받는 곳 (참고 — KIS 문서로 확인 필요)

프론트가 알기로는 한국투자증권 "국내업종 현재지수"로 받는다.

- **경로:** `/uapi/domestic-stock/v1/quotations/inquire-index-price`, tr_id `FHPUP02100000`
- **입력:** `FID_COND_MRKT_DIV_CODE=U`, `FID_INPUT_ISCD`는 `0001`(코스피)·`1001`(코스닥)
- **응답:** `bstp_nmix_prpr`(현재 지수)·`bstp_nmix_prdy_vrss`(전일 대비)·`bstp_nmix_prdy_ctrt`(전일 대비율)

필드 이름과 부호가 실제로 어떻게 오는지는 확인해 주면 좋겠다.
